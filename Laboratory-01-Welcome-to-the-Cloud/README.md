# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory introduces Linux and cloud computing using KillerCoda.

## Objectives

- Explore a Linux environment
- Practice basic Linux commands
- Create and manage files and directories
- Build a GitHub cloud computing portfolio

## Activities Performed

- Launched Linux using KillerCoda
- Created a Linux user
- Investigated system information
- Created directories and Markdown files
- Documented the laboratory activity using GitHub

## Linux Commands Used

- whoami
- pwd
- hostname
- uname
- lscpu
- free
- df
- mkdir
- touch
- ls

## Skills Learned

I learned how to use basic Linux commands and how to document my laboratory activities using GitHub.
