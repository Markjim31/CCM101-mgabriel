# Reflection

## What I Learned

I learned the basic commands and concepts of Linux. I also learned how to use the terminal to check information about the computer and manage files and users. This activity helped me understand more about how operating systems work.


## My Experience with Linux


My experience with Linux was new and a little challenging at first because I was not used to using commands in the terminal. As I practiced, I became more comfortable with the commands and understood how they work. It was a good experience because I learned something different from the usual Windows environment.

## My Experience with KillerCoda


My experience with KillerCoda was helpful because I was able to practice Linux commands using an online environment. I did not need to install Linux on my computer, which made the activity easier. I also learned by following the instructions and trying the commands myself.

## My Experience with GitHub

My experience with GitHub helped me understand how to create and manage a repository and upload my work online. I also learned how a README file can be used to describe a project and provide important information. At first, GitHub was a little confusing, but I became more familiar with it as I used it.
