# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview
This laboratory activity focused on understanding the basic components of cloud infrastructure. I learned how cloud providers use computing resources, storage, networking, and identity management to build and manage cloud-based systems. I also practiced Linux commands using the terminal.

## Objectives
Understand the basic components of cloud infrastructure.
Learn the purpose of compute, storage, networking, and IAM.
Practice using basic Linux commands.
Check system information using the Linux terminal.
Gain experience working with a cloud-based Linux environment.

## Cloud Infrastructure Components
Compute – Used to run applications, programs, and virtual machines.
Storage – Used to store files, databases, and other types of data.
Networking – Connects cloud resources and allows them to communicate with each other.
IAM (Identity and Access Management) – Controls users, permissions, and access to cloud resources.
