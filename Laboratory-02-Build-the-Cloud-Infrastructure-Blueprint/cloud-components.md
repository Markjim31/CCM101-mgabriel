# Cloud Components

## Compute

Compute provides processing resources for applications and workloads.

## Storage

Storage provides a place to store files and data.

## Networking

Networking allows systems and services to communicate.

## Operating System

The operating system manages computer resources and provides an environment for applications.

## Relationship to KillerCoda

KillerCoda provides a Linux environment where compute storage networking and operating system concepts can be explored.
