# AWS Research

## Overview

Amazon Web Services (AWS) is a cloud platform that provides a broad range of services for computing, storage, databases, networking, security, analytics, and machine learning. AWS services can be accessed through the AWS Management Console, AWS CLI, and software development kits.

## Global Infrastructure

AWS operates cloud infrastructure through regions and Availability Zones around the world. This infrastructure allows organizations to deploy resources in different geographic locations.

## Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable compute capacity in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) helps control access to AWS resources and services.

## Three Advantages

1. Wide range of cloud services.
2. Scalable cloud infrastructure.
3. Multiple tools for managing and developing cloud applications.

## Use Cases

AWS can be used for web applications, data storage, databases, analytics, machine learning, backup, and enterprise applications.
