# Google Cloud Research

## Overview

Google Cloud is a cloud computing platform that provides services for computing, storage, networking, databases, analytics, artificial intelligence, and machine learning.

## Global Infrastructure

Google Cloud infrastructure is organized into regions and zones. These locations contain physical infrastructure used to run Google Cloud services and workloads.

## Management Console

Google Cloud provides a web-based console for managing cloud resources and services.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machine instances for running workloads on Google Cloud.

### 2. Cloud Storage

Cloud Storage provides object storage for storing and retrieving data.

### 3. Google Cloud VPC

Google Cloud VPC provides networking capabilities for Google Cloud resources.

### 4. Identity and Access Management

Google Cloud IAM provides fine-grained access control for managing permissions to cloud resources.

## Three Advantages

1. Strong data analytics and machine learning capabilities.
2. Managed services for modern cloud applications.
3. Integration with Google Cloud infrastructure and developer tools.

## Use Cases

Google Cloud can be used for web applications, data analytics, machine learning, Kubernetes workloads, storage, databases, and cloud-native applications.
