# Reflection

This laboratory activity helped me understand the differences and similarities among AWS, Microsoft Azure, and Google Cloud. I learned that the three providers offer similar categories of cloud services, including computing, storage, networking, identity, analytics, and artificial intelligence.

One important lesson I learned is that different cloud providers use different names for services that can perform similar functions. For example, AWS uses Amazon EC2 for compute, Azure provides Azure Virtual Machines, and Google Cloud provides Compute Engine. Understanding these equivalents makes it easier to compare cloud platforms.

I also learned how cloud platforms can be evaluated based on the requirements of a client. A company that already uses Microsoft technologies may consider Azure because of its Microsoft ecosystem, while other organizations may have different requirements involving analytics, machine learning, applications, or existing infrastructure.

Using KillerCoda also helped me connect Linux resources with cloud infrastructure. The CPU, memory, disk, and networking resources available in the Linux environment can be related conceptually to cloud compute, storage, and networking services.

Overall, the activity improved my understanding of multi-cloud computing and showed me that choosing cloud services involves examining requirements rather than simply looking at one service in isolation.
