# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage using MinIO, an S3-compatible object storage server deployed using Docker.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through a web interface.
- Create a storage bucket and upload an object.
- Document cloud storage operations.

## Tools Used

- KillerCoda
- Ubuntu
- Docker
- MinIO
- GitHub

## Skills Learned

- Cloud storage concepts
- Docker deployment
- Object storage management
- Bucket creation
- File uploading
- Technical documentation
