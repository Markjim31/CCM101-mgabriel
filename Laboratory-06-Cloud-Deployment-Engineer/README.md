# Laboratory 06: The Cloud Deployment Engineer

## Mission Overview

This laboratory focuses on deploying a multi-tier cloud application using Docker Compose. The application uses Nextcloud as the web tier and MariaDB as the database tier.

## Objectives

* Understand two-tier architecture.
* Create a Docker Compose YAML file.
* Deploy Nextcloud and MariaDB containers.
* Access the Nextcloud setup page.
* Document the deployment process using Markdown.

Commands used during the deployment will be documented here.

## Skills Learned

* Linux command-line operations
* Docker Compose
* YAML configuration
* Multi-container deployment
* Infrastructure as Code (IaC)
